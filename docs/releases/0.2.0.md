# @integration-testing/testcontainers 0.2.0

Version 0.2.0 adds an opt-in live dashboard and self-contained HTML reports for generated Jest and Vitest projects.

## Highlights

- Enable the dashboard with `dashboard: true` in either `defineContainerProject` or `defineAnnotationProject`.
- Inspect shared and file-dedicated containers, mapped ports, container startup, application bootstrap, test execution, failures, and cleanup activity.
- Filter, sort, and paginate test results, compare test durations with the run average, and inspect explicitly enabled container logs.
- Keep multiple Vitest watch reruns in one live session while saving a report for every completed run.
- Use the same feature with Jest or Vitest, annotation mode or project configuration mode, and NestJS or another Node.js backend.
- Preview the dashboard in the README through a screenshot captured from a real Vitest run with shared RabbitMQ and dedicated PostgreSQL containers.

## Backward compatibility

This release is additive and remains compatible with existing 0.1.0 project and annotation configurations:

- The dashboard is disabled unless `dashboard` is supplied.
- Existing package export paths, container APIs, runner lifecycle modules, worker settings, and configured reporters remain available.
- The serialized annotation and project configuration version remains `2`; `dashboard` is an optional field.
- Node.js, TypeScript, Jest, and Vitest compatibility ranges are unchanged.
- No dashboard framework, browser automation package, database client, ORM, or web framework was added to runtime dependencies.

Applications upgrading from 0.1.0 do not need to change their configuration. Add `dashboard: true` only when the dashboard is wanted.

## Quick start

```ts
export default defineContainerProject({
  dashboard: true,
  include: ['test/**/*.integration.test.ts'],
  containers: {
    database: postgreSql({ isolation: 'dedicated' }),
  },
});
```

Run the normal Jest or Vitest command, open the printed `127.0.0.1` link, and find the completed self-contained report under `test-results/integration-testing/<run-id>/index.html`.

See the npm README section [Live local dashboard](../../packages/testcontainers-integration/README.md#live-local-dashboard) for configuration, privacy, CI, timing, and limitation details.

## Publication contents

The npm package continues to publish only `dist`, `README.md`, `LICENSE`, and `package.json`. The dashboard HTML template is embedded into the compiled JavaScript for both ESM and CommonJS; source HTML, source tests, runner fixtures, screenshots, and browser tooling are not published.
